# Contributing to Prompt Shield

Thanks for contributing to Prompt Shield!

Prompt Shield is an AI security research project focused on prompt injection, jailbreaks, prompt leakage, adversarial testing, and AI-system security.

## How to Contribute

1. Create a new branch for your changes.
2. Make your changes.
3. Test your changes locally.
4. Commit and push your branch.
5. Open a pull request.

## Good Contributions

Useful contributions include:

- New detection techniques
- Security tests
- Adversarial attack research
- Bug fixes
- Documentation improvements
- UI improvements
- Evaluation and benchmarking

## Security

Only test AI systems and applications that you are authorized to test.

Do not submit passwords, API keys, private information, or other sensitive data.

For security-sensitive issues, see `SECURITY.md`.

## Pull Requests

Please keep pull requests focused and clearly explain:

- What you changed
- Why you changed it
- How you tested it

Thanks for helping improve Prompt Shield!
